What DecentAI is

A platform for running AI agents under your control.

The model proposes; the platform decides.

Ships empty

On day one the platform has people, groups and an audit trail, and no agents. Nothing can act until an administrator installs something.

Every agent declares itself

Before it is installed, an agent declares each thing it can do, how far each one reaches, the records it keeps, the secrets it needs and the hosts it connects to.

Installed like an app

An administrator reads the declaration and installs one exact version, checked byte for byte. Nothing updates itself: a new version is a new review.

Held to it on every call

Every call is checked against the agent's declaration, your organization's rules and the chat's trust. Above that trust, a person approves first.

Isolated while it works

Each agent runs in a sandbox of its own, with its own files and its own network, and reaches only the hosts it declared.

Written in any language

An agent is a program and a manifest, written to one published standard. Your ERP or internal portal can have its own agent, under the same controls.

Details

Where it runs, and what stays yours

DecentAI runs inside your environment.

Nothing about your people, your conversations or your data passes through us.

Your environment

On your own computer, or on your own servers or cloud account. There is no hosted version: the platform runs where you run it. One installation can serve several organizations, each kept apart.

Your AI model

Choose from over two hundred providers, or a model you host yourself. You hold the keys. The model sees the conversation; it never sees a credential.

Your data

Conversations, documents, records, credentials and the audit trail stay in your deployment. Secrets are encrypted, and reach only an agent you listed, during a call.

Open source

Free software under the Apache-2.0 licence: read it, run it, change it. Updates are installed when you choose, and agents' updates through your own review.

What leaves your environment is listed and yours to limit: the conversation to the model you chose, an agent's calls to the hosts it declared, and notifications where you send them.

How to start

On your own computer, in minutes.

  1. 1

    Run it

    Clone the platform and run one command. It sets DecentAI up with Docker, generates every password and key, and serves it to this computer only.

  2. 2

    Open the web client

    Start the web client beside it, give it the address and the first run's code, and name your organization: you are its administrator.

  3. 3

    Add a model and agents

    Connect the AI model you choose, add an agent catalog, install each agent after reading what it declares, and ask for the work in plain words.
