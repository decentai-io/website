# decentai.io

The DecentAI website, served by GitHub Pages from this repository's `main` branch at decentai.io (`CNAME`).

Each page is one HTML file, served without its extension: `index.html` (home), `product.html`, `agents.html`, `developers.html`, `download.html`, `about.html` (the company behind DecentAI), `privacy.html` (the apps' privacy policy) and `support.html`, all styled by `site.css`; there is no build step. The privacy and support pages are the ones the app stores link to: keep their addresses. The marks in `brand/` and `favicon.ico` are copies of the ones in the [desktop repository](https://github.com/decentai-io/decentai-desktop-app/tree/main/brand), whose `brand.md` governs their use.
