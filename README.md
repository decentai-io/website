# decentai.io

The DecentAI website: one static page, served by GitHub Pages from this repository's `main` branch.

`index.html` and `site.css` are the whole of it; there is no build step. The marks in `brand/` are copies of the ones in the [desktop repository](https://github.com/decentai-io/decentai-desktop/tree/main/brand), whose `brand.md` governs their use.
