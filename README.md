# decentai.io

The DecentAI website, served by GitHub Pages from this repository's `main` branch at decentai.io (`CNAME`).

`index.html` (the home page), `privacy.html` (the apps' privacy policy, at `/privacy`), `support.html` (at `/support`) and `site.css` are the whole of it; there is no build step. The marks in `brand/` and `favicon.ico` are copies of the ones in the [desktop repository](https://github.com/decentai-io/decentai-desktop/tree/main/brand), whose `brand.md` governs their use.
