Get DecentAI.

Run the platform yourself, then reach it from a browser today, and from your desktop and phone soon. Everything here is free and open source.

Step 1

The platform

Needs Docker with Compose, and Python 3.9 or later. On Windows, macOS or Linux.

git clone https://github.com/decentai-io/decentai.git
cd decentai
python deploy/setup/setup.py

The first time, it generates every password and key, builds and starts DecentAI, and prints its address, http://localhost:4280, served to this computer only, with the first run's code. python deploy/setup/setup.py --link shows them again.

To run it on a server and keep it running, follow operating in the documentation.

Step 2

The web client

The app people use in a browser. Start it beside the platform:

git clone https://github.com/decentai-io/decentai-web-client.git ../decentai-web-client
cd ../decentai-web-client && docker compose up -d --build

Open http://localhost:4300, give it the platform's address and the first run's code, and name your organization and yourself: you are its administrator. The web client is static files, so it can also be hosted anywhere, as its hosting guide explains.

Step 3

Agents

In the web client, open Agents, then Marketplace, and add a source with either address. No credential is needed.

https://raw.githubusercontent.com/decentai-io/decentai-agents/main/catalog/catalog.json
https://raw.githubusercontent.com/ahmed-dirir/decentai-browser/main/catalog/catalog.json

The first is thirty-seven agents for mail, calendars, files, documents and records; the second, a real web browser. What each one does.
